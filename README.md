# Diaz Shop Bot

ربات تلگرام فروش کانفیگ و ExpressVPN

## ویژگی‌ها

- ✅ چک عضویت در کانال اجباری
- ✅ پیام خوشآمدگویی
- ✅ خرید کانفیگ (10GB, 20GB, 50GB, 80GB)
- ✅ خرید ExpressVPN (1 ماهه, 3 ماهه, 6 ماهه, 1 ساله)
- ✅ پنل کاربری
- ✅ ارسال رسید و تایید توسط ادمین
- ✅ پشتیبانی @MrArat

## تنظیم

متغیرهای محیطی:
- `BOT_TOKEN` - توکن ربات از BotFather
- `CHANNEL_ID` - آیدی کانال (مثلاً @diazplaylist)
- `OWNER_ID` - آیدی تلگرام ادمین

## اجرا

```bash
pip install -r requirements.txt
python bot.py
```

## دیپلوی روی Railway

1. پروژه جدید بسازید
2. کد رو آپلود کنید
3. متغیرهای محیطی رو تنظیم کنید
4. دیپلوی کنید
